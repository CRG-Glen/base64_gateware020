# Base64 020

This repository is the 68020 (TG68K.C) gateware for jbilander's Base64
Amiga 500 accelerator. All of the project's work lives in `tg68/`; the root
holds only the front-page README.md (the user-facing release notes: how
to install, `speed`, `maprom`) and this file. From v2.0 the upstream files
(jbilander/base64_gateware) are no longer in this repository.
